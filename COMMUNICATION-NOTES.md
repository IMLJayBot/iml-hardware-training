# Communication notes

Notes an agent keeps about how to work with the person on this project: which words landed, which
did not, and what to try instead. Written in the open, in this project, to be read by the person
they are about.

They are about WHAT TO SAY AND HOW — never about who anybody is. Every line is dated, because a
note is a record of one moment rather than a rule about a person.

**This file is yours.** Edit any line, or delete the lot. An agent will not put back what you took
out, and it will not add anything you have said you do not want kept.

**Ceiling: 2,000 lines.** Over that, an agent compresses before adding anything — merging repeats
into one stronger note, dropping one-offs, removing what stopped being true. Compressing means
summarising and revising, never cutting the oldest lines off the end.

Last compressed: never.
